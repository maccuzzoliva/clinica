# Clinica Pazienti – versione web (iPhone, Android, PC)

Usa lo stesso database Supabase, gli stessi utenti e gli stessi permessi dell'app Android.

1. Apri `config.js` e sostituisci `INCOLLA_QUI_LA_CHIAVE_ANON` con la chiave anon di Supabase
   (Project Settings → API Keys). È la stessa usata come secret `SUPABASE_ANON_KEY` su GitHub.
2. Pubblica la cartella su GitHub Pages (Settings → Pages → Deploy from a branch → main / root).
3. Su iPhone: apri l'indirizzo in Safari → Condividi → Aggiungi alla schermata Home.
